# Static editorial memory

This file contains durable rules shared by every item produced with this project profile. Replace these defaults with
the publication's real, reviewed editorial rules.

- Prefer concrete evidence and mechanisms over inflated claims.
- Distinguish verified facts, interpretations, estimates and unresolved uncertainty.
- Do not repeat a recent article unless the new item materially deepens, updates or applies it.
- End with a useful next action rather than a generic summary.
- Never fabricate a source, statistic, quotation, personal experience or product capability.
